dawruh. admin

Панель меняет файлы сайта в репозитории dawruh/dawruh.github.io. Для входа нужен личный GitHub-токен с доступом только к этому репозиторию.

  1. Открой github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → dawruh.github.io
  3. Permissions → Repository permissions → Contents → Read and write
  4. Нажми Generate token, скопируй и вставь сюда

Токен хранится только в этом браузере и отправляется только на api.github.com.
